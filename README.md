# Interactive Entrepreneur Showcase — Kim Kardashian

An interactive, editorial-style portfolio exploring **Kim Kardashian’s evolution from media personality to entrepreneur, business founder, and cultural influencer.**

The project combines luxury-inspired visual design, interactive storytelling, and researched content to showcase her entrepreneurial journey across beauty, fashion, shapewear, entertainment, and business.

## ✦ Project Overview

The Interactive Entrepreneur Showcase is a React-based website designed to present Kim Kardashian’s professional journey through an immersive digital experience. It highlights key milestones, business ventures, cultural influence, and entrepreneurial lessons through a structured, visually engaging interface.

Rather than functioning as a traditional biography, the website presents her journey as a combination of personal branding, strategic business development, media influence, and product innovation.

## ✦ Key Features

- **Interactive Hero Section:** An immersive opening experience introducing the showcase.
- **Entrepreneurial Timeline:** Explore key milestones in Kim Kardashian’s professional and business journey.
- **Business Venture Explorer:** Discover her ventures through interactive cards, industry filters, and detailed modal views.
- **About Section:** Learn about her background, professional identity, and entrepreneurial positioning.
- **Business Impact:** Explore her influence across beauty, fashion, entertainment, and popular culture.
- **Entrepreneurial Takeaways:** Discover lessons related to branding, audience engagement, diversification, and business growth.
- **Dark and Light Themes:** Switch between two visual themes for a personalized experience.
- **Responsive Navigation:** Navigate the website through a mobile-friendly menu.
- **Scroll-Based Animations:** Experience subtle transitions, reveal effects, and scrolling interactions.
- **Interactive Venture Modals:** Navigate between venture details using Previous and Next controls.
- **Source References:** Access references supporting factual content throughout the showcase.
- **Reading Progress Indicator:** Track progress while exploring the website.
- **Reduced-Motion Support:** Respect accessibility preferences for reduced animation.

## ✦ Design Philosophy

The interface follows a luxury editorial art direction inspired by fashion publications, premium beauty brands, and contemporary digital portfolios.

**Visual direction**
- Plum-noir backgrounds with restrained rose-toned accents.
- Elegant typography and clear visual hierarchy.
- Spacious layouts with carefully balanced content.
- Refined cards, subtle glow effects, and understated transitions.
- A cohesive dark and light theme system.
- Minimal visual clutter and a focus on content.

**Experience goals**

The website aims to feel polished, immersive, and professional while maintaining a distinctive editorial identity. Animations and interactive elements support the storytelling rather than distracting from it.

## ✦ Technology Stack

- **React 18** — Component-based user interface.
- **Vite 5** — Development server and production build tooling.
- **JavaScript (ES Modules)** — Application logic and interactive behaviour.
- **CSS3** — Layout, responsive styling, transitions, themes, and visual effects.
- **React Hooks** — Shared state and reusable interaction logic.
- **Local Storage** — Persistence of the selected theme.

No backend is required for the current frontend experience.

## ✦ Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### 1. Extract the project

Unzip the downloaded project folder and open a terminal inside the `kim-showcase` directory.

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the website.

### 4. Create a production build

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## ✦ Interactive Experience

The showcase integrates several interactions to create a more engaging browsing experience:

1. Explore the entrepreneurial timeline to discover milestones.
2. Filter business ventures by industry.
3. Select a venture card to open its detailed modal.
4. Navigate between ventures without leaving the current view.
5. Switch between dark and light themes.
6. Scroll through sections enhanced with subtle reveal effects.
7. Explore references and supporting information.

The interface is designed to work across desktop and mobile screen sizes.
